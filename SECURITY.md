# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/PixelSam123/amxmodx-webhook-reporter/security/advisories/new)
(Security -> Advisories -> Report a vulnerability). If that is unavailable,
open an issue that describes the problem **without** including any secret.

## Never post secrets

A Discord webhook URL is a credential: anyone who has it can post to the
channel. Do not paste webhook URLs or tokens into issues, pull requests,
screenshots, or logs. If a URL is exposed, delete that webhook in Discord
(Channel Settings -> Integrations -> Webhooks) and create a new one.

## Supported versions

Only the latest release is supported with security fixes.
